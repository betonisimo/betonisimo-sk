# SEO stránky miest

Реализовано 29.10.2026. Новый раздел находится в **Administrácia → SEO
stránky miest** (`/admin/city-pages`). Первичная проверка выполнена локально;
результаты перечислены ниже.

## Работа клиента

1. Нажать **Nová stránka** и задать название, например `Betónové ploty Trnava`.
2. URL автоматически предложит `/betonove-ploty-trnava`. Его можно задать
   отдельно в поле **URL adresa**, вводя только часть после домена.
3. Добавить вводный текст, необязательную обложку и основной контент через тот
   же BlockNote-редактор, который используется в блоге: H2/H3, абзацы, списки,
   фотографии с alt и подписями, ссылки на выделенный текст. Есть предпросмотр
   и отдельные поля meta title/description.
4. **Uložiť koncept** сохраняет черновик. **Publikovať stránku** открывает
   готовую страницу для посетителей и автоматически добавляет её в sitemap.
5. В списке **Duplikovať** создаёт независимый черновик с копией содержания,
   фотографий и SEO-полей. Название получает пометку `kópia`, адрес — отдельный
   уникальный slug. После редактирования копию нужно опубликовать явно.

В опубликованной странице можно изменить URL: предыдущие адреса перенаправят
на актуальный с HTTP 308. **Presunúť medzi koncepty** закрывает страницу и
удаляет её из sitemap; повторная публикация возвращает её обратно. Удаление
страницы требует подтверждения. Оригинал и другие дубликаты не затрагиваются.
Файлы фотографий не удаляются из Blob: ими может пользоваться другая копия.

## Карточки каталога на странице города

В редакторе есть блок **Vzory z katalógu** с поиском и выбором образцов из
`/katalog`. Отмеченные карточки появляются под основным текстом в том же
оформлении, что и каталог; их также видно в предпросмотре. Без выбранных
образцов блок скрыт. Кнопка **Zrušiť výber** убирает весь выбор. Можно отметить
до 100 образцов. Раздел дополняющих товаров `/doplnky` в этот выбор не входит.

В JSON страницы хранится только массив `collectionIds`, без копирования
названий, фотографий и URL. Публичная страница берёт актуальные записи каталога,
включая alt фотографий. При изменении или удалении образца кэш страниц городов
сбрасывается; удалённые карточки перестают отображаться. При следующем
сохранении страницы ссылки на удалённые записи очищаются. Порядок карточек
соответствует порядку выбора. Дубликат наследует выбор, который затем можно
изменить независимо от оригинала. Старые страницы без `collectionIds`
продолжают работать с пустым блоком; миграция базы не нужна.

## Публичный сайт и поиск

- Страницы открываются прямо из корня сайта: `/{slug}`.
- Автоматических ссылок в меню, футере, главной, блоге или каталоге нет,
  согласно заданию. Ссылки доступны в административном списке.
- В sitemap включаются только опубликованные страницы, с основным доменом
  `https://www.betonissimo.sk` и настоящим временем последнего изменения.
- Опубликованная страница отдаёт полный HTML без необходимости JavaScript,
  один H1, своё canonical/og:url, заголовок и описание. Отдельного
  BlogPosting/Product/вымышленного LocalBusiness для этих страниц нет.
- Черновики, удалённые и неизвестные страницы возвращают 404/noindex.
- Sitemap помогает обнаружению URL, но не гарантирует индексацию Google.
  [Документация Google](https://developers.google.com/search/docs/crawling-indexing/sitemaps/overview).

## Хранение и маршруты

Миграция базы не нужна. Данные сохраняются в существующей StrankaObsah:

- `stranka = seo-city-page`, уникальная `sekcia = seo-city-page-{UUID}`;
  JSON содержит version 1, название, slug, режим URL, блоки version 2, фото,
  SEO-поля, статус, даты и `collectionIds`. ID строки является стабильным ID страницы.
- `stranka = seo-city-url`, `sekcia = seo-city-url-{slug}`; JSON содержит
  pageId. Текущие и прошлые URL закреплены за стабильным ID.

Сохранение и резервирование URL выполняются одной Serializable-транзакцией с
ограниченными повторами конфликтов. Автоматический URL при совпадении получает
номер. Занятые ручные адреса, адреса существующих разделов и попытки ввести
домен/путь/параметры отклоняются. Исторические адреса не используются повторно,
даже после удаления страницы. Доступ к любому изменению проверяется на сервере;
записи других разделов StrankaObsah нельзя редактировать через эти действия.

`/[citySlug]` использует генерацию статического HTML при первом запросе и ISR
с интервалом 3600 секунд. Сохранение, публикация, смена статуса и удаление
инвалидируют страницы этого маршрута и sitemap, без нового деплоя. Закрытые
черновики не доступны через публичный предпросмотр; предпросмотр — в админке.

Бэкап базы должен включать обычные записи StrankaObsah и резервирования URL.
Дублирование копирует ссылки на фотографии, а не создаёт повторные файлы в Blob.
